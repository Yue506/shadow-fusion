# 背景保护优先探索

用户新授权继续本地 CPU 探索。优先级：真实非编辑背景颜色和内容保护；然后是编辑区校色、回贴范围与边界。本轮不自动续启定时任务、不新增付费推理。旧轮主测试已看过，不用于本轮选择。

R0 假设：拒绝不符合光照变化的色度／纹理残差，以及 mask 外只迁移亮度变化，能够抑制消除候选的背景重绘。匹配比较前期保守硬连接单级、窄羽化、光度守卫、亮度迁移及其组合；上一轮选定配置只作参照。

先跑已知真实五图和两条件 60 图探索集；旧五图仅用于开发回归。统一保留投影召回、影子 RGB 误差和原 mask 覆盖，避免通过全拒绝取得背景保护。以背景改动率、超过 3 级的改动率、背景最大通道差与高频内容差作为首要证据；同时看逐图最差病例。只在探索后冻结候选，再查看原二十验证集，不重新使用已开封的旧最终测试。

新模块默认关闭，原模式保持不变：guard=photometric/chroma/texture/none，transfer=luminance/rgb，feather=compact 为两像素有限外扩；均可显式消融。光度一致不等于语义归属正确，亮度迁移可能不能恢复带色投影或真正变化的背景；不声称达到真实背景绝对不变。


R1 诊断：严格光度守卫即使取消空间关联也漏掉大部分真实影子，不是简单连接断裂。R2 相对亮度置信固定使用 sRGB 亮度增量/最大(20,原图亮度)，4%→20% 过渡，并乘原绝对门控。R3 比较局部校色、单级/窄/无羽化。R4 比较绝对门控 2→5、4→8、6→12，以及保留原细节的 sRGB 亮度偏移迁移；亮度迁移的色差代价必须记录，不能只看区域召回。

进入复用验证集的五配置及规则在代码提交时冻结。最低条件是每候选条件召回≥0.8、扰动 IoU≥0.95、影子 RGB 误差不超过保守基线1.2倍加1。通过后先最小化最坏候选条件背景误改；5%相对或0.05百分点工程近似带内，再考虑影子色差、真实标注边界梯度和耗时。不把近似带当成统计等价。旧验证也曾用于前轮开发，本轮独立测试另取未使用的20张原生图，排除前100和已知5图，通过文件名、pHash和几何检查；仍是作者参考构造代理，不是新增模型生成。


## 本轮结果

完成R0–R4探索、复用20验证和新增20张图片代理测试。新方法没有通过预定验证召回≥80%条件，选型回退保守单级；未修改门槛。另将固定背景优先候选 `relative_gate612` 在新20图评价，未依结果继续调参。

| 前轮代理选定 | 1.3210% | 90.2725% | 5.7610 |

仅目标代理，背景优先候选召回76.47%，保守单级80.53%；影子RGB误差分别19.147、16.888。新候选更容易漏影，不能称为全面替代。实际已知五图：背景误改13.85%→保守7.86%→候选3.25%；超过3级误改10.16%→6.42%→2.45%。候选召回96.68%、投影RGB误差17.021（保守99.23%、16.505）。已知案例不是独立泛化证据。

真实五图外边界RGB误差由保守14.934降至12.745，但边界梯度误差25.997→26.770，窄羽化并未全面改善接缝。两类边界证据均保留。严格光度guard与亮度迁移分别导致严重漏影及色差恶化，不作为默认。

用户优先背景保护时，可显式试用 `configs/background_first_candidate.json`（相对置信、绝对6→12、两像素窄羽化、sRGB平面校色、硬连接）。`configs/background_first_selected.json` 是验证回退的保守配置。模式及模块仍可独立消融；不要将候选标作已验证优胜。

新增20图片的原生池计数元数据有变量重名错误，已按1012原档案减140条记录排除项修正为872；冻结选图、PNG哈希、候选和推理参数均未改变。公开清单可重建160张PNG；不公开原图及生成候选。

21项单元测试、原60输出逐像素兼容回归及新输出范围外审计通过。原main与基线标签保持不变。本轮是用户新授权的人工跟进，旧一次性Goal及定时任务保持暂停；不自动续跑。
