# 100 图影子编辑区域探索协议

目标优先级：稳定、精确地预测原 mask 之外应当编辑的目标投影；控制对非目标背景和其他物体的误改；随后才优化校色、接缝与耗时。

## 数据与分割

从有来源和目标／投影标注的数据中选择 100 张独立场景图片，覆盖硬影、软影、长影、纹理地面、跨材质、暗背景、邻近其他投影。优先使用原生图像，避免直接从论文拼图中放大。按场景分组去重，避免同一照片的不同目标跨分割。

固定种子 42，按场景与难度分层分为 60 张探索、20 张验证、20 张最终测试。测试标签不用于阈值选择或失败驱动修正。原有十图只作回归及已知失败案例，不冒充新的独立测试集。新增数据若不足 100 张，报告真实数量和缺口，不以重复图补数。

物体 mask 不含目标投影。投影标注和受保护背景标签仅进入评价。消除候选在各策略间冻结。若使用数据作者的配对去影参考或已知背景构造代理候选，必须标成代理条件；不伪称真实消除模型输出，也不把用真值构造候选的优异结果当作泛化证据。正式生成候选与代理条件分开统计。

## 多轮探索

每轮先记录可检验假设，固定一项主要变化，保留成功与失败结果。先复现 `mask`、`tracefusion`、`shadow`、`shadow+gamma` 基线，再探索：背景偏移补偿、同材质／局部颜色锚点、正亮度与纹理约束、非目标对象保护、软影与远端投影连接、置信度拒绝和有限空间约束。

每轮记录模块配置、源代码提交、数据清单哈希、逐图指标、按场景分组的结果及耗时。将 shadow precision、recall、F1、IoU 与背景误改率并列。优先降低误检并控制漏检，不按扩大支持域得到的 recall 单指标选冠军。

对候选图的小幅全局色偏、亮度偏移与弱噪声做固定扰动，检查预测区域的稳定 IoU 和最差场景表现，记录扰动大小与种子。像素保护分别报告“预测范围外严格相同”与“真实标注背景是否被误改”。最终最多选一次测试集进行比较；未达到严格背景保护要求时明确写未达成。

## Git 与复现

从发布的 `baseline-20261021` 标签创建 `explore/shadow-regions-20261021` 分支；若名称已有，检查其状态并复用匹配的探索分支。每轮工作可继续拆分子分支，但不得直接覆盖 `main` 或基线标签。有效轮次提交代码、配置和精简日志；原图、候选、权重与大体积结果保持在忽略目录，发布数值或预览前检查来源及隐私。

运行 `python -m unittest discover -s tests -v`。保留关闭新模块时的既有行为；若有意改变算法，以新配置记录结果，不悄悄替换旧预设。停止前保存当前分支、未完成步骤、最优已验证配置和实际失败模式，避免把预算停止写成质量目标达成。
